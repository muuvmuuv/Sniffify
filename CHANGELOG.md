## Version 1.0.0

### German

```
Der erste amtliche Release. Die App, die es nie hätte geben dürfen.

• Amtliche Line-Berechnung aus Größe und Gewicht — in echter Größe auf dem Bildschirm
• Tabak-Box wie eine Baustelle abgesteckt, daneben die lila Nasen-Spur
• Film-Countdown 3…2…1 mit Challenge-Stoppuhr: Die Line muss komplett weg, verpatzte Züge laufen einfach weiter (unter 1,5 s: PERFEKT!)
• Mikrofon-Schummelschutz inkl. Röhrchen-Analyse und Nasenerkennung (WÜRDIG 👃)
• Der kleine Schaufel-Helfer begleitet jeden Zug und räumt hinterher auf
• Bestenliste: Maximilian ist dir eine Nasenlänge voraus. Immer.
• Sniffify Wrapped: Jahresrückblick mit Nasenkilometern, schnellster Nase und teilbarem Bild
• Bildschirm bleibt wach, Rotation gesperrt, Abbruch nur per gehaltenem Schloss
• Kein Tracking, kein Account, alles bleibt auf dem Gerät
```

### English

```
The first official release. The app that should never have existed.

• Official line calculation from height and weight — rendered at true physical size
• Tobacco box marked out like a construction site, purple nose track alongside
• Film countdown 3…2…1 with challenge stopwatch: the line must be completely gone, botched pulls just keep running (under 1.5 s: PERFEKT!)
• Microphone anti-cheat incl. tube-vs-direct analysis and nose detection (WORTHY 👃)
• The little shovel buddy follows every pull and cleans up afterwards
• Leaderboard: Maximilian is one nose-length ahead of you. Always.
• Sniffify Wrapped: year recap with nose-kilometers, fastest nose, and a shareable image
• Screen stays awake, rotation locked, exit only via the held lock
• No tracking, no account, everything stays on device
```
